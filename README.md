## 先确认你需不需要 Pro

付费方式选得再精，档位选错了也白搭。免费版其实已经给了不少东西：扩展思考、联网搜索、跨对话记忆、文件创建、代码执行都包含在内，甚至带 Slack 和 Google Workspace 集成。如果你一周只问三五次短问题，免费版完全够用，这 20 美元可以省下。

两边的核心差异长这样：

|  | Free | Pro |
| --- | --- | --- |
| 价格 | $0 | $20/月（年付约 $17/月） |
| 单次会话用量 | 基础额度 | 至少 5 倍 |

出现这些信号，升级才有实际意义：

- 每周都会碰到“用量已达上限”；
- 你想用 Claude Code——这个编程 agent 只在付费套餐开放，免费版连试用都没有；
- 你的 Projects 已经顶到免费版 5 个的上限；
- 工作日需要 Claude 连续处理任务，受不了中间停下来等重置。

## Pro 订阅里到底有什么

除了用量翻倍，Pro 里比较值钱的是这几样：

- **Claude Code**：在终端和 IDE 里运行的编程 agent，支持 VS Code、Cursor、JetBrains 系列。它包含在订阅内，共用套餐的用量池，不按 token 另收钱；
- **Claude Cowork**：桌面端 agent，能跨文件、跨应用处理多步骤任务，2026 年 1 月起对 Pro 用户开放；
- **Research**：多步骤深度调研模式，自动检索并整合带来源的结果；
- **无限 Projects**：按客户、项目、代码库随意开工作区，每个都能带着自己的知识文件和自定义指令；
- **Microsoft 365 和 Outlook 集成**，加上高峰期优先访问和新功能抢先体验；
- **Claude Design** 等较新的功能面也在 Pro 的覆盖范围内。

> 需要单独说清楚的一点：**Pro 不包含 API 额度**。订阅覆盖 claude.ai 网页端、桌面和移动应用以及 Claude Code；API 是另一套按 token 计费的独立账单，要做开发接入得单独开 Console 账户。这是新订阅者最常见的账单误会。

## 用量限制：比价格更影响体验的部分

Pro 的用量不是无限的，它由两套机制同时管着：一个滚动重置的 5 小时会话窗口，外加一个跨所有模型的每周上限。官方给的说法是“至少 5 倍于免费版的单次会话用量”，具体数字从不公布——因为实际额度取决于消息长度、附件大小、对话历史和所用模型。

第三方流传的实测说法是标准对话大约 45 条/5 小时。把它当参考值就好，别当承诺。

几个实际使用中会碰到的细节：

- 会话窗口是滚动的，不是每天零点清零。上午 9 点用完额度，下午 2 点就恢复满额。把用量摊开在整个工作日，一天能拿到的总条数远比集中突击多——持续使用的用户一天跑到 200 条以上是可能的，而在 90 分钟里梭哈的人很快就会撞墙。
- Claude Code 和 Cowork 跟聊天共用同一个池子。写代码要处理整个文件和长上下文，消耗速度比聊天快得多，一场高强度编程可能不到一小时就把 5 小时窗口烧完。
- 每周上限在固定的星期和时间重置，每个账户的时点不同，具体可以在 Claude 界面的 Settings → Usage 里查。

真撞上限了，有四条路：等 5 小时窗口重置；开启 usage credits，超出部分按标准 API 费率计费；升级到 Max 档；或者给 Claude Code 配一个 API key，把编码流量走 API 计费，把 Pro 的额度留给聊天和轻任务。

## 常见问题

### Claude Pro 月付可以随时取消吗？

可以。在 Settings → Billing 里取消后，订阅延续到当前计费周期结束，不会立刻断供，也没有额外条件。

### 月付和年付的功能有区别吗？

没有。两种方式买的是同一个 Pro，模型、用量和工具完全一致，区别只有价格和付款节奏。

### Claude Pro 有官方优惠码吗？

没有。Anthropic 不运营优惠码、促销码或联盟返利活动，官方唯一的省钱方式是年付。优惠码只出现在第三方渠道，比如 Bewild 的 ACCPAY 可立减 1 美元。

### Pro 包含 API 额度吗？

不包含。API 按 token 单独计费，与订阅互不相干，需要程序化访问就单独开 API 账户。

### 免费版和 Pro 的用量差距有多大？

官方口径是 Pro 至少 5 倍于免费版的单次会话用量。免费版实际大约每天 30 到 100 条消息、每 4 到 8 小时重置一次，具体随模型和用法浮动。
